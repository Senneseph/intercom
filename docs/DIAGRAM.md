## Content Distribution

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│                          Content Distribution                           │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

Original Content (e.g., image)
┌───────────────────────────────────────────────────────────────┐
│                                                               │
│                       Complete Image                          │
│                                                               │
└───────────────────────────────────────────────────────────────┘

Split into Pieces (16KB chunks)
┌───────────┬───────────┬───────────┬───────────┬───────────┬───────────┐
│  Piece 0  │  Piece 1  │  Piece 2  │  Piece 3  │  Piece 4  │  Piece 5  │
└───────────┴───────────┴───────────┴───────────┴───────────┴───────────┘

Distribution Across Peers
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│    Peer A     │     │    Peer B     │     │    Peer C     │
├───────────────┤     ├───────────────┤     ├───────────────┤
│   Piece 0     │     │   Piece 0     │     │   Piece 2     │
│   Piece 1     │     │   Piece 2     │     │   Piece 3     │
│   Piece 2     │     │   Piece 4     │     │   Piece 5     │
└───────────────┘     └───────────────┘     └───────────────┘

When a new peer joins:
┌───────────────┐
│    Peer D     │
├───────────────┤
│   (empty)     │
└───────────────┘
         │
         ▼
┌───────────────┐
│    Peer D     │
├───────────────┤
│   Piece 0     │ ◄── From Peer A or B
│   Piece 2     │ ◄── From Peer A, B, or C
│   Piece 5     │ ◄── From Peer C
└───────────────┘
```

## Data Flow

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│                              Data Flow                                  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

Content Creation
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│  User creates │     │ Content split │     │ Metadata and  │
│    content    │────►│  into pieces  │────►│pieces stored  │
│               │     │               │     │   locally     │
└───────────────┘     └───────────────┘     └───────────────┘
                                                    │
                                                    ▼
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│ Peers request │     │ Metadata sent │     │ Peers receive │
│ missing pieces│◄────│   to peers    │◄────│   metadata    │
│               │     │               │     │               │
└───────────────┘     └───────────────┘     └───────────────┘

Content Consumption
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│ User requests │     │ Check local   │     │ Request any   │
│    content    │────►│   storage     │────►│ missing pieces│
│               │     │               │     │  from peers   │
└───────────────┘     └───────────────┘     └───────────────┘
                                                    │
                                                    ▼
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│  Content is   │     │ Content hash  │     │ Pieces are    │
│ displayed to  │◄────│  verified     │◄────│ assembled into│
│     user      │     │               │     │complete content│
└───────────────┘     └───────────────┘     └───────────────┘
```
